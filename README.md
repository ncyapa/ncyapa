## AI & Research

### Evaluating Synthetic Data Pipelines in Medical AI via Explainable AI

Research focused on evaluating traditional and diffusion-based synthetic data augmentation across CNN and Vision Transformer architectures for breast cancer classification.

Key areas included:

- CNN and Vision Transformer architectures
- Synthetic data pipelines
- Diffusion-based augmentation
- ROC-AUC and Macro F1 evaluation
- Grad-CAM visualization
- Synthetic artifact analysis
- Model generalization and overfitting

### Advancements in Deep Learning for Breast Cancer Detection using GAN and ResNet

Research exploring synthetic mammography data generation and deep-learning-based breast cancer classification.

Key areas included:

- GAN-based synthetic data generation
- Modified DCGAN architecture
- ResNet-18
- Medical image classification
- Deep learning model training and evaluation

The trained ResNet-18 model achieved **86.5% classification accuracy** on real-world mammography data.
